# FoodLoop

This branch (foodloop-complete) contains the initial scaffold for the FoodLoop application: Vite + React + TypeScript + Tailwind and a Firebase emulator-friendly helper. Run the app locally with the emulator for development.

Quick start:
1. git checkout foodloop-complete
2. npm ci
3. cp .env.example .env and fill in (or set USE_EMULATOR=true to use local emulators)
4. npm run dev

This is the first commit: more features (auth, Firestore models, cloud functions, UI) will follow in small milestones.
